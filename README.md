## 🎯 Sobre este Repositório
O objetivo aqui é manter um registro organizado de tudo o que foi codificado em conjunto com o professor. Este espaço serve como meu material de consulta rápida para revisar sintaxe, entender a implementação prática dos conceitos e guardar aqueles trechos de código que resolvem dúvidas específicas do dia a dia.
